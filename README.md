Scam Website Scanner

Overview

Scam Website Scanner is a cybersecurity-focused web application designed to help users identify phishing and scam websites before accessing them. The project analyzes URLs using AI-powered detection through the Google Gemini API and generates detailed security reports to improve online safety and cybersecurity awareness.
Features

AI-powered phishing and scam website detection
URL and domain security analysis
Risk score generation and threat assessment
SSL certificate verification
Server location analysis
Phishing history and security indicators
Interactive dashboard with data visualization
Local database and system log maintenance
Responsive user interface using Tailwind CSS
Dynamic charts powered by Chart.js
Enhanced visual experience with Three.js
Technologies Used
HTML
CSS
JavaScript
Tailwind CSS
Chart.js
Three.js
Google Gemini API
How It Works
Enter a website URL.
The system analyzes the URL using AI-powered detection.
Security indicators such as SSL status, domain information, and phishing patterns are evaluated.
A detailed report with a risk score and recommendations is generated.
Users can review results through an interactive dashboard.
